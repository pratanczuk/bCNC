# Tablet Wi-Fi Setup for Plotter

Use these steps to connect the tablet to your Wi-Fi network.

## 1. Locate the Gear Icon
Look at the bottom-right panel near the clock (for example, **8:04**).
Click the **Gear** icon (⚙️) located between the blue/yellow icon and the eject symbol (⏏).

## 2. Open Available Networks
- Left-click (or right-click, depending on desktop layout) the gear icon.
- Open the list of scanned Wi-Fi networks (SSIDs).

## 3. Select Your Wi-Fi Network
Click your Wi-Fi network name from the list.

## 4. Enter the Password
When prompted:
- Enter your network password (Pre-Shared Key / PSK)
- Click **Connect** or **OK**
